# Flutter 国际化系列教程索引

本教程基于 Flutter 官方文档编写，旨在帮助开发者从零开始掌握 Flutter 应用的国际化（i18n）与本地化（l10n）。

## 教程列表

- **[第 01 章：基础入门](./01-introduction.md)**
  - i18n 与 l10n 概念、环境搭建、基础配置及区域设置覆盖。
- **[第 02 章：gen-l10n 自动化工具](./02-gen-l10n.md)**
  - 使用 `gen-l10n` 工具自动生成类型安全的翻译代码。
- **[第 03 章：占位符、复数与选择器](./03-placeholders-and-plurals.md)**
  - 处理动态变量、复杂复数规则及基于类别的条件翻译。
- **[第 04 章：数字、货币与日期格式化](./04-formatting.md)**
  - 根据不同 Locale 自动适配数值、货币符号和日期显示格式。
- **[第 05 章：高级配置与平台适配](./05-advanced-config.md)**
  - iOS 平台配置、多变体 Locale 定义（如简繁体中文）及解析逻辑。
- **[第 06 章：底层原理与手动工作流](./06-internal-mechanics.md)**
  - 深入理解 `InheritedWidget` 工作机制及不依赖工具的手动实现方案。

---

## 快速查阅指南

- **初学者**：建议按照 01-04 的顺序学习。
- **进阶开发者**：可直接查阅 05 和 06 了解底层逻辑与高级适配。
- **项目维护者**：重点参考 02 了解如何配置自动化生成流程。
